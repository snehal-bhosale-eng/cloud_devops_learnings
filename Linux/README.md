# Linux

This section documents my hands-on Linux learning as part of my
DevOps and Cloud Engineering preparation.

## Learning Approach

I follow:

1. Learn the concept
2. Practice it in Linux
3. Troubleshoot mistakes
4. Document what I learned
5. Revise with interview questions

## Topics Covered

- Linux Fundamentals
- Filesystem and Navigation
- Paths
- File and Directory Management
- Copy, Move and Rename
- Bash Configuration Files
- Aliases
- File Permissions
- Process and Resource Management
- Package Management
- Users and Groups
- SSH
- File Transfer
- Linux Networking
- Bash Scripting

## Hands-on Practice

All concepts are practiced directly in a Linux environment rather
than being learned only theoretically.
